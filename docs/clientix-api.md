# Green Clinic Intelligence — API для Клиентикс

## Адрес API

```text
https://green-clinic-intelligence-green-clinic.vercel.app/api/knowledge
```

API предназначен только для чтения. Запросы `POST`, `PUT`, `PATCH` и `DELETE`
через этот адрес недоступны. Карточки, цены и подготовка остаются управляемыми
только в Green Clinic.

## Авторизация

Для каждого запроса передаётся заголовок `apikey` со значением **Supabase
Publishable Key** проекта Green Clinic. Это публичный ключ чтения, а не пароль
от базы и не service-role key. Его передаёт Green Clinic отдельно, не храните
его как секрет администратора и никогда не заменяйте им server/service key.

```http
apikey: <GREEN_CLINIC_PUBLISHABLE_KEY>
```

## Методы

| Метод | Назначение |
| --- | --- |
| `GET /health` | Проверка доступности и число карточек |
| `GET /modules` | Список разделов и количество карточек |
| `GET /search?q=<текст>` | Поиск по жалобам, услугам, исследованиям, артикулам и сценариям |
| `GET /cards/<id>` | Получение одной сценарной карточки |
| `GET /cards?module=<раздел>&limit=80` | Карточки выбранного раздела |
| `GET /lab-catalog?limit=80` | Каталог лабораторных исследований |

Поиск возвращает как сценарные карточки, так и лабораторные исследования.
Для лабораторных исследований используйте поля `code`, `price`, `biomaterial`,
`prep` и `duration`.

## Пример поиска

```bash
curl -G 'https://green-clinic-intelligence-green-clinic.vercel.app/api/knowledge/search' \
  -H 'apikey: <GREEN_CLINIC_PUBLISHABLE_KEY>' \
  --data-urlencode 'q=герпес'
```

## Правила интеграции

1. Запрашивайте API в момент поиска или обновляйте локальный кэш не реже одного раза в час.
2. Не копируйте базу в Клиентикс вручную: тогда новые карточки, цены и исправления Green Clinic будут доступны автоматически.
3. Не интерпретируйте медицинский результат. Показывайте текст карточки как подсказку администратору.
4. Не используйте и не запрашивайте доступ к PostgreSQL, Supabase service key или панели Vercel.

## CORS

В production API разрешены кросс-доменные `GET`-запросы, поэтому Клиентикс может
обращаться к нему из своего веб-интерфейса. Изменение данных через этот API
невозможно.
