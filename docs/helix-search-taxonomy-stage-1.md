# Черновик таксономии поиска: справочники Helix

**Этап 1.** Это не каталог услуг и не медицинские рекомендации. Документ задаёт поисковые кластеры, разговорные формулировки пациента и теги для будущих лабораторных карточек. На следующем этапе к подтверждённым исследованиям будут привязаны артикул Green Clinic, цена, тип биоматериала, подготовка и срок выполнения.

**Статус:** черновик для согласования. В Supabase не загружался.

## Правила поиска

- Запрос пациента может состоять из жалобы, названия болезни, органа, вида анализа, сокращения или бытового слова. Все варианты ниже должны вести в один тематический кластер.
- Теги пишутся строчными буквами, через запятую; названия исследований и методы остаются отдельными полями будущей карточки.
- Не ставим диагноз и не обещаем результат. Запрос «болезнь Крона» означает «показать исследования по теме и предложить уточнить назначение врача».
- Для одного исследования допустимо несколько кластеров: например, `калпротектин` относится и к `жкт`, и к `воспалительные заболевания кишечника`, и к `кал`.
